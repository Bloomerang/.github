# Xray Upload Skill

Upload test results or test cases to Xray (Jira test management) using `jira-test-uploader.py`.

## Trigger Conditions

Invoke this skill when the user asks to:
- Upload test results to Xray or Jira
- Import test cases into Xray
- Sync test execution results with Jira
- Push JUnit / Cucumber / Xray JSON reports to Xray

## Required Environment Variables

Check that these are set before proceeding. If any are missing, tell the user which ones and stop.

| Variable | Description |
|----------|-------------|
| `JIRA_BASE_URL` | Jira instance URL, e.g. `https://yourcompany.atlassian.net` |
| `JIRA_USERNAME` | Jira username or email address |
| `JIRA_API_TOKEN` | API token from https://id.atlassian.com/manage/api-tokens |
| `JIRA_PROJECT_KEY` | Jira project key, e.g. `PROJ` |

For **Xray Cloud** (upload results via Xray's dedicated API), also require:

| Variable | Description |
|----------|-------------|
| `XRAY_CLIENT_ID` | Xray Cloud client ID (from Xray API Keys page) |
| `XRAY_CLIENT_SECRET` | Xray Cloud client secret |

## Steps

1. **Verify environment**

   Run:
   ```bash
   python3 ~/.claude/skills/xray-upload/jira-test-uploader.py --check-env
   ```

   If variables are missing, show the user which ones and link to the relevant docs.

2. **Identify what to upload**

   Ask the user (or infer from context) which of these applies:

   - **Test results** (JUnit XML, Cucumber JSON, Xray JSON) — produced by a CI run
   - **Test cases** (Xray JSON) — generated by the test-plan skill

   Search the project for result files if not specified:
   ```bash
   find . -name "*.xml" -path "*/test-results/*" -o \
          -name "*.xml" -path "*/surefire-reports/*" -o \
          -name "cucumber*.json" -o \
          -name "test-plan.json" 2>/dev/null | head -20
   ```

3. **Run the uploader**

   ### Upload JUnit XML results
   ```bash
   python3 ~/.claude/skills/xray-upload/jira-test-uploader.py \
     --type junit \
     --file <path/to/results.xml> \
     --project-key "$JIRA_PROJECT_KEY"
   ```

   ### Upload Cucumber JSON results
   ```bash
   python3 ~/.claude/skills/xray-upload/jira-test-uploader.py \
     --type cucumber \
     --file <path/to/cucumber.json> \
     --project-key "$JIRA_PROJECT_KEY"
   ```

   ### Create test cases from test-plan.json
   ```bash
   python3 ~/.claude/skills/xray-upload/jira-test-uploader.py \
     --type create-tests \
     --file test-plan.json \
     --project-key "$JIRA_PROJECT_KEY"
   ```

   Add `--test-execution-key PROJ-123` to attach results to an existing Test Execution issue.

4. **Report results**

   - On success: show the Jira links to created/updated Test Execution and Test issues.
   - On failure: show the error message and suggest a fix (e.g., wrong project key, expired token, bad file format).

## Notes

- The script is located at `~/.claude/skills/xray-upload/jira-test-uploader.py`.
- Xray Cloud uses a separate authentication token endpoint; the script handles this automatically when `XRAY_CLIENT_ID` and `XRAY_CLIENT_SECRET` are set.
- For Xray Server / Data Center, basic auth with `JIRA_USERNAME` + `JIRA_API_TOKEN` is used against the Jira REST API directly.
