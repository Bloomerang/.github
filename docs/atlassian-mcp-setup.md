# Atlassian MCP Setup

1. Type `/mcp` in the chat input and press Enter
2. A dialog will appear listing MCP servers — look for **claude.ai Atlassian**
3. Click on it (don't dismiss the dialog)
4. You should see an option to **Connect** or **Authenticate** — click that
5. A browser window or URL will open for OAuth — log in with your Atlassian/Jira credentials
6. After authorizing, come back and confirm it's done

If the dialog is showing but you're not sure what to click, let me know what you see and someone can help from there.
